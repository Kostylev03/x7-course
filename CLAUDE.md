# x7-course — инструкция для Claude-сессий

## Состояние проекта — STATUS.md (общий контекст между сессиями)
- В начале сессии прочитай STATUS.md в корне проекта (единый источник правды: где сейчас, доступы, открытые баги, что дальше).
- В конце обнови STATUS.md и сделай commit + push. Состояние держим в STATUS.md (в git), не в чате.
- Секреты — только в *.local.md (вне git); в STATUS.md лишь указатель.
- Репо правят несколько сессий параллельно: коммить точечно (git add <файлы>), НЕ git add -A; перед коммитом git status.
